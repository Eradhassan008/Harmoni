# Harmoni MVP - Tasks

Order reflects how the project was actually built. Checkboxes reflect reality.

## app.py track (UI)

- [x] **Foundation** - minimal Streamlit project: `app.py`, `ai.py`,
  `analytics.py` stubs, `requirements.txt`, Python `.gitignore` (replacing the
  Node one), README, `data/` folder; four sidebar destinations, condition
  picker (PCOS/Thyroid/Both + thyroid subtype), theme, footer; smoke test.
- [x] **A1a - Care Plan + Daily Journal UI** - photo/paste/manual inputs, editable
  review table keeping original wording, Confirm gate, grouped checklist; journal
  with task checkboxes, note, symptoms, period, review-before-save, editable
  saved entries.
- [x] **A1b - Insights + Doctor Summary + JSON backup** - three Insights charts
  and My Health Summary; Doctor Summary 30/90-day filter, preview, PDF/CSV
  downloads; "Demo storage - not secure medical storage" JSON download/upload.
- [x] **A2 - Integration** - wire real sample data in; parsing/grouping/safety
  fixes (header skipping, medication-line merging, twice-daily grouping,
  "Needs review" gate); use synthetic history + new records in Insights and
  Doctor Summary, distinguished and labelled.
- [x] **Honest labels + pattern detection** - rule-based observations labelled
  "Detected automatically from your records"; only live `call_ai` text labelled
  "AI-generated"; demo text labelled "Sample output - not generated by live AI";
  week-over-week drop/rise detection with dates from the data (no hard-coded
  dates).
- [x] **Connect AI and analytics** - all four pages wired to the live shared
  functions; photo-without-vision routes to manual entry; journal symptom
  extraction with review; AI observations + care_tasks + journal_entries passed
  into `make_doctor_pdf`.
- [x] **Theme and final polish** - lavender/sage theme, home dashboard, logo;
  welcome name = Aisha (fictional); "Follow-ups & lab tests" focus area;
  checklist items shown once without timing/Qty/Refills; chart axes (0-100%,
  1-5) and clean cycle date labels; doctor table index hidden, cycle stats
  "all-time"; white text on purple buttons; readable disabled button.
